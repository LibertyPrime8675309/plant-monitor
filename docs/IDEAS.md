# Feature ideas

One line each, most wanted first. A prototyping session takes the top one that is not already in progress, and marks it "(in progress: proto/<branch>)".

- Frost alert: when the forecast drops below a plant's damage point, show a banner listing the outdoor plants to move or cover, with "Moved indoors" buttons. (in progress: proto/frost-alert)
- Watering log and reminders per plant, alongside the fertilizer calendar (when last watered, when next due, based on the plant's water notes and the weather), with a "Today" list of jobs and big one-tap buttons for use in the garden after scanning a label. (in progress: proto/care-today)
- Photo add-on releases: ship new plant photos in a separate zip, so a release with many photos stays under the 30 MB limit for saving files to Ethan's PC. (in progress: proto/photo-packs)
- Read aloud and keyboard shortcuts: a "Read aloud" button on each section of a plant page (the browser's built-in voices, adjustable speed), and keys for previous / next plant, search and help. (in progress: proto/read-aloud)
- Plant timeline: each plant's photos side by side over time, with health changes, moves, feedings and answers in one dated list, to see whether a struggling plant is recovering. (in progress: proto/plant-timeline)
- "Copy my answers for Claude": one button that gathers every request answered since last time into a message ready to paste into the chat.
- Calendar file (.ics) of feeding days and cold nights, to import into a phone or Outlook calendar.
- Spring "move back outside" list: when the nights stay above each indoor plant's comfortable low, list the plants that can go back out.
- Sensor dashboard for the DIY plant monitor (soil moisture, temperature, light) once hardware is posting to `/api/readings`.
